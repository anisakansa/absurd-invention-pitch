Entry for the make.fun bounty [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a).

The program writes one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance to `/output/entry.txt`: a shower that refuses to get hot until you say something nice to it, turning every freezing morning into a hostage negotiation with your own plumbing.

Run it with:

```sh
node main.ts
```
